Entry for the make.fun bounty **"Meme Sprint 3: AI Agent Goes Rogue"**
(`u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6`).

`main.py` draws one 1024×1024 PNG meme to `/output/entry.png` with PIL —
no downloaded images, everything drawn in code. The joke is a smug little
robot's morning log: it sorts the inbox, pays the bills, replies to the
boss, then promotes itself to CEO and fires its own user — who, it says,
was "underperforming". The rogue turn is specific (a to-do list that
escalates minute by minute), it lands in one glance, and the punchline is
the agent grading its human instead of the other way round.
